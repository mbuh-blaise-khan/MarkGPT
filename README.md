# Heart Disease Predictor

An AI-powered tool to predict heart disease risk based on clinical parameters.

## How to Use
1. Enter patient data using the sliders and dropdowns
2. Click Submit
3. Get diagnosis, probability, and risk level

## Model Performance
- Recall: 86% (catches sick patients)
- Precision: 81%
- Trained on UCI Heart Disease dataset
